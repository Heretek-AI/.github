# Contributing

These rules apply to people and to coding agents. A repository's own
`CONTRIBUTING.md` or `AGENTS.md` overrides them.

- **Read the repo's `AGENTS.md` first** when it has one. It holds that repo's
  invariants and commands.
- **Work on a branch and open a pull request.** Merging to the default branch
  and publishing a release are a maintainer's decision.
- **Show evidence.** A pull request states which commands were run and what
  they printed, and names anything that was not run.
- **Use repo-relative paths in tracked files.** Refer to other repositories as
  `owner/name`. Paths into a home directory describe one machine and leak its
  layout.
- **Report vulnerabilities privately.** See `SECURITY.md`.
