# Heretek-AI

Open-source agentic engineering, developer tooling, AI inference infrastructure, and game development projects.

## Flagship Repositories

| Repository | Focus |
| --- | --- |
| [`IUMBTEMS`](https://github.com/Heretek-AI/IUMBTEMS) | Agentic reasoning and epistemic tooling |
| [`claude-4-opencode`](https://github.com/Heretek-AI/claude-4-opencode) | OpenCode integration and compatibility layer |
| [`opencode-teamwork-v2`](https://github.com/Heretek-AI/opencode-teamwork-v2) | Multi-agent teamwork orchestration for OpenCode v2 |
| [`scraper-swarm`](https://github.com/Heretek-AI/scraper-swarm) | Distributed Python/uv scraping and ingestion swarm |
| [`awesome-opencode`](https://github.com/Heretek-AI/awesome-opencode) | Curated directory of OpenCode plugins, themes, agents, and resources |
| [`GDevelop-Unlocked`](https://github.com/Heretek-AI/GDevelop-Unlocked) | Open BYOK AI harness and extensions for GDevelop |
| [`game-engine`](https://github.com/Heretek-AI/game-engine) | Native C++20 Flecs/Jolt/Vulkan + .NET game engine |
| [`homebrew-tap`](https://github.com/Heretek-AI/homebrew-tap) | Bottle-first Homebrew tap for AI inference engines and CLI tools |
