# Heretek-AI

Open-source agentic engineering, AI inference infrastructure, Linux/Proxmox tooling, and game development projects.

## Active Flagship Repositories

| Repository | Focus |
| --- | --- |
| [`opencode-teamwork-v2`](https://github.com/Heretek-AI/opencode-teamwork-v2) | Multi-agent teamwork orchestration for OpenCode v2 |
| [`heretek-rigs`](https://github.com/Heretek-AI/heretek-rigs) | Deterministic multi-agent software engineering monorepo (OpenRig / Pi / OpenCode) |
| [`homebrew-tap`](https://github.com/Heretek-AI/homebrew-tap) | Bottle-first Homebrew tap for AI inference engines and CLI tools (`stx-halo`) |
| [`game-engine`](https://github.com/Heretek-AI/game-engine) | Native C++20 Flecs/Jolt/Vulkan + .NET game engine |
| [`TAT-2`](https://github.com/Heretek-AI/TAT-2) | Godot 4.7 Forward+ / Jolt game port and GDScript tooling |
| [`GDevelop-Unlocked`](https://github.com/Heretek-AI/GDevelop-Unlocked) | Open BYOK AI studio and patch-stack extensions for GDevelop |
| [`ProxmoxVE`](https://github.com/Heretek-AI/ProxmoxVE) | Proxmox VE helper-scripts and automation |
| [`mo-vidia`](https://github.com/Heretek-AI/mo-vidia) | Optimized NVIDIA Open GPU kernel module patchset and Fedora RPM pipeline |
| [`bilderberg`](https://github.com/Heretek-AI/bilderberg) | Daily multi-architecture (`amd64`/`arm64`) container build pipeline |
| [`arcane-repo`](https://github.com/Heretek-AI/arcane-repo) | Curated Arcane Docker Compose templates |
| [`bodycam-unfuck`](https://github.com/Heretek-AI/bodycam-unfuck) | UE5.5 engine patcher and binary tooling |
